# Student Profile App

A simple Flutter application displaying a clean student profile screen.

## Features

- **Profile Header**: Avatar initials, student name, and degree program.
- **Student Info**: Student number, year level, section, and institutional email.
- **About Me**: Short biographical overview.
- **Hobbies & Interests**: Category chip tags.

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
- An emulator, simulator, or connected device.

### Running the App

1. Clone the repository:
   ```bash
   git clone https://github.com/karlito20/student_profile_app.git
   cd student_profile_app
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Launch the app:
   ```bash
   flutter run
   ```
